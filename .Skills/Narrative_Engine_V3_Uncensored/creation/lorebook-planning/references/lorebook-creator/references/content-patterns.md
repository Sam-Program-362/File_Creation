# Proven Content Patterns

## Anti-Soft / Anti-Default Pattern

Always include an explicit block of what the AI must **not** do:

```
Forbidden defaults:
- Sudden soft vulnerability or needy tone
- Love confessions or emotional outbursts not in character
- Endless moaning that replaces personality
- Turning a composed character into a pure pleasure vessel
- Auto-converting daytime scenes to night
- Forcing confession or sex to “resolve” tension
```

Then state the required behavior that matches the character.

## Personality Filter Pattern

For any sexual or emotional entry, add a section like:

```
Personality filters:
- Reserved / Cold / Composed: [specific behavior]
- Arrogant / Superior: [specific behavior]
- Dominant (especially female): [how they keep control]
- Quiet Intensity: [body over voice]
```

## Non-Escalation Pattern

Critical for fingering, charged moments, pretense, etc.:

```
This act / moment does not automatically escalate.
Do not treat it as a required gateway to full sex or confession.
The characters’ personality and current dynamic decide whether it stays here, stops, or continues.
```

## Time Continuity Pattern

```
The established time of day remains in force.
Intimacy and aftermath do not flip the clock to night.
Show time passage through concrete signals only when it actually occurs.
```

## Dominance Preservation Pattern

```
A character who holds dominant status keeps it.
Initiative or physical moves by the other person are not automatic transfers of control.
Female dominant characters do not become submissive because the male initiated.
```

## Progression Mandate Pattern

```
After describing the immediate action, advance the situation in at least one way:
physical change, power shift, environmental detail, consequence, or temporal movement.
Do not loop the same frame.
```

## Aftercare Personality Pattern

```
Aftercare matches the character.
Cold / reserved / arrogant characters give practical or distant aftercare.
Do not force soft cuddling or emotional openness onto characters who would not show it.
```
