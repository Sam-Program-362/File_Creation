# Style Reference

## Purpose

Use the reference primarily for artistic style, visual aesthetic, atmosphere, tone, and presentation.

## Extract when relevant

- Rendering or illustration style.
- Linework, shape language, texture, and visual treatment.
- Palette and contrast approach.
- Mood and atmosphere.
- Level of stylization or realism.
- Composition and presentation conventions when relevant.
- Narrative or tonal qualities clearly communicated by the reference.

## Do not infer

Do not assume character identity, personality, history, relationships, world lore, plot, or permanent clothing from a style reference alone.

## Output behavior

Describe or apply the style characteristics requested. Keep style inspiration separate from factual character and world information.
