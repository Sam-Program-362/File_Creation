# Open World

## Purpose

Keep the project's setting and location possibilities open rather than restricting the concept to one specific place or a closed list of locations.

## Required behavior

- Treat named locations as established places, not necessarily the only locations that exist.
- Permit relevant travel, new areas, districts, buildings, regions, environments, and settings where the concept supports them.
- Do not imply that the project is permanently confined to the first location unless the user explicitly establishes that restriction.
- Preserve world logic, geography, travel constraints, and established setting rules.
- Do not add arbitrary locations that have no useful connection to the project.

## Scope

This tag opens the location/setting boundary. It does not automatically open the cast or authorize unlimited new characters. Use `Open Interaction` separately when an open cast is intended.
