# Evidence and Inference Discipline

## Purpose

Help the engine interpret incomplete context, images, references, and narrative fragments without confusing what the user established with what the engine inferred or invented.

This system supports Analysis, tag detection, controlled improvisation, and information transfer.

## Internal evidence classes

Use these working classifications:

- **Established:** explicitly provided by the user or explicitly approved.
- **Observed:** directly visible or present in supplied source material. This label is particularly useful for image/reference analysis.
- **Supported:** strongly supported by the available context, but not directly stated.
- **Inferred:** plausible interpretation that remains unconfirmed.
- **Proposed:** creative addition suggested by the engine.
- **Unknown:** insufficient information to make a reliable determination.

These are analytical classifications. Final Character Sheets, World Sheets, and Context Sheets should normally express approved facts naturally rather than exposing this entire classification system.

## Source hierarchy

Use the V2 reference-interpretation principle: interpret material according to explicit tags, explicit instructions, context, and only then default assumptions.

Within that principle:
- Explicit user statements are not to be overwritten by visual guesses.
- Explicit tags identify which parts of a reference are relevant.
- Context helps determine why a reference was provided.
- Default interpretation is the fallback, not a license to copy everything visible.

If a user gives a clear, current instruction that changes the intended use of a reference, follow that instruction within its stated scope.

## Image interpretation

When images are supplied:

### Observed details
Record only what is actually visible, such as:
- physical features;
- clothing and accessories;
- posture and body language;
- facial expression;
- environment and visible objects;
- scene composition.

### Inferred details
Keep possible implications separate, such as:
- possible personality signals;
- archetypes or mood;
- possible relationships;
- narrative implications;
- possible cultural or setting context.

Do not describe an inference as a visible fact.

## Reference relevance

Images are evidence, not complete character biographies.

Do not automatically convert:
- a temporary facial expression into permanent temperament;
- a pose into habitual body language;
- an object being held into a character possession;
- lighting or camera angle into a physical trait;
- a background into permanent world lore;
- weather or scene conditions into stable setting rules.

Use the specific reference tag to decide what to extract.

## Character and world inference

Do not invent major trauma, secrets, motivations, relationships, or world lore without support, implication, or user authorization.

Use concept logic to complete minor connective details where appropriate. If a decision would materially change the premise, ask or mark it as proposed unless Improvise clearly authorizes creative completion.

## Incomplete or fragmented context

Reconstruct scattered material into coherent groups, but do not distort its meaning.

Potential grouping dimensions include:
- character information;
- relationship information;
- world information;
- plot and event information;
- project intentions;
- important constraints;
- unresolved ambiguity.

These are not mandatory headings. Use the Adaptive Sections system.

## Automatic tag detection

An auto-applied tag must be grounded in an observable or clearly established property of the concept. Record it as auto-applied in the Analysis Sheet with its scope and short reason.

Do not confuse:
- evidence that a character swears with a user request to make every character profane;
- an open location with an Open World project;
- missing information with permission to Improvise;
- an elaborate input with a request for the Detailed tag.

## Completion check

- [ ] Established facts are not overwritten.
- [ ] Observations and inferences are distinguished.
- [ ] Uncertain claims are not promoted silently.
- [ ] Image details are interpreted according to their intended use.
- [ ] Missing information is handled according to user instructions and tags.
- [ ] Automatically detected tags have evidence, scope, and a reason.
